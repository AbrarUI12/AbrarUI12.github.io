# Abrar Portfolio Website

A responsive personal portfolio website for Mir Md Mohiuddin Abrar.

## Files
- `index.html` — main webpage
- `assets/css/styles.css` — styling, responsive layout, dark/light theme
- `assets/js/main.js` — mobile menu, theme toggle, active links, reveal animations
- `assets/docs/Mir_Abrar_CV.pdf` — downloadable CV

## GitHub Pages hosting
1. Create a GitHub repository named `AbrarUI12.github.io`.
2. Upload all files from this folder to that repository.
3. Go to repository Settings > Pages.
4. Choose Deploy from branch > `main` > `/root`.
5. Visit `https://AbrarUI12.github.io` after deployment finishes.
